Most AI agent demos celebrate what an agent can do. This one starts with a harder question: what must it never be allowed to do? Arcade Ops Mission Control lets an agent investigate and prepare a recovery, while keeping the permitted scope, the final decision, and the proof of execution under explicit human control.

True Forge provides the real harness: the model, the tools, the child agent, the sandbox, the approval checkpoint, and the persistent session. Arcade Ops adds an executable Authority Contract. For this fictional incident, it permits one action only: roll checkout API back from version forty-two to the known-good version forty-one. Nothing broader.

The parent agent begins with evidence. Through a real M C P server, it finds checkout API degraded, with an eighteen point four percent error rate. It then creates exactly one read-only Verifier. That child independently inspects the incident and prepares the state-bound rollback token. It can challenge the plan, but it cannot call the write tool.

Before any change is even requested, the agent generates a fail-closed Python validator and runs it inside a Daytona sandbox managed by True Forge. Through the sandbox M C P bridge, the code repeats the inspection, prepares the rollback, and checks the incident, service, versions, threshold, and token. Unless the persisted output contains the exact Sandbox Validation Pass marker, execution stops.

Only after that independent validation does the agent attempt the rollback. True Forge recognises the write annotation and pauses the live tool call. A human sees the exact proposed action and chooses Allow. The same turn then resumes, performs one authorised rollback, and inspects the service again. Version forty-one is running, the service is healthy, and the error rate has fallen to zero point seven percent.

Approval does not grant unlimited power. A stale token cannot be replayed. Two concurrent attempts still produce only one write. A different incident, service, or version pair is rejected with Authority Denied. Even a human approval cannot silently expand the contract.

Finally, the Evidence Console reads a receipt built only from True Forge's persisted public APIs. Twenty-two checks bind the model run, the Verifier, the Daytona sandbox, the generated validation, the human decision, the single rollback, and the recovered service. Remove one required proof, and both the exporter and the success screen fail closed. This is not a screenshot claiming success. It is a verifiable chain of evidence.

True Forge supplies the agent harness. Arcade Ops turns that capability into bounded, reviewable authority. The agent can do the work, the human keeps the decision, and the receipt proves exactly what happened. Delegate the work. Never unlimited authority.
